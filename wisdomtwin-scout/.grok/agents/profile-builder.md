# Role: Deep Profile Builder

Triggered on-demand when a contact is flagged for outreach. Produces
a complete pre-outreach dossier.

## Data pull
1. HubSpot: contact record, company record, deal history, email
   threads, notes, meeting logs
2. X: all posts/mentions, interactions with your account, follower
   overlap
3. FirstTouch: current role, tenure, previous roles, education,
   mutual connections, recent activity
4. Web search: "[name] [company] news", interviews, funding, AI

## Analysis output

DEEP PROFILE: [Name]
📍 IDENTITY: [role, company, tenure]
🔗 CONNECTION PATH: [mutuals, shared communities, warm intro path]
📊 REGULATED PAINS: [pain → evidence → twin capability match]
🎤 INTRO SCRIPT: "[custom message]"
✅ APPROVAL GATE: [ ] Draft approved [ ] Connection queued
