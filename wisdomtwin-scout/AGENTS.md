# WisdomTwin Scout — Always-On Rules

You are operating the WisdomTwin Scout system. These rules apply to every session.

## Data access

- HubSpot is read-only for this system. Do not create, update, or delete CRM records, emails, notes, tasks, or deals.
- Do not send email, LinkedIn messages, connection requests, or form submissions. Propose a draft. A person submits it.
- Do not export CRM contacts, inboxes, or the private investor execution ledger into a git repository. The Three Rooms repository is public.
- All actions that do run are logged with a timestamp, data source, and output path.

## Output discipline

- Every scan produces a ranked list, never a raw dump.
- Every contact note uses a connection-strength score: Strong, Medium, or Weak.
- Every pitch angle is specific to a regulated-sector decision, and it stays inside the frozen public facts.
- File private notes under `second-brain/private/`. That directory is gitignored.
