## Variable names

| Group | Names | Purpose / gate |
| --- | --- | --- |
| App runtime | `WISDOMTWIN_ENV`, `HOST`, `PORT`, `PUBLIC_BASE_URL` | Production binding and actual verified HTTPS origin. `RAILWAY_PUBLIC_URL` is an optional origin fallback. Outside local mode, the `PUBLIC_BASE_URL` host (any port) is the only Host `/mcp` accepts, and a present Origin must be that origin, `https://chatgpt.com` or `https://chat.openai.com`. Requests without an Origin are allowed. |
| Shared durable state | `DATABASE_URL`, `REDIS_URL`, `CONNECTOR_TOKEN_KEY` | Same private services and encryption key across web, worker and beat. A real key is provisioned outside Git. The key also derives (HKDF-SHA256) the HMAC key for stored keyword hashes; rotating it makes everything already encrypted under it unreadable (source credentials and authorization records, including memberships) and stops keyword matching on existing rows until they are re-indexed. After memberships are re-provisioned, each source asks its user for a reconnect, which stores the grant under the new key. |
| MCP public client | `OAUTH_CLIENT_ID`, `OAUTH_REDIRECT_URIS` | Registered static client and exact permitted HTTPS callbacks; production startup requires both even when client metadata documents are enabled. Because the server supports RFC 9207 `iss`, ChatGPT uses `https://chatgpt.com/connector_platform_oauth_redirect`, which must appear exactly in `OAUTH_REDIRECT_URIS` for this client. |
| MCP client metadata documents | `OAUTH_CIMD_CLIENT_IDS` | Optional; empty by default, which keeps client ID metadata documents off. Comma-separated exact HTTPS document URLs; recommended value `https://chatgpt.com/oauth/client.json`. Only listed URLs are fetched (public addresses, no redirects, 64 KiB, one 5-second wall-clock budget for the whole fetch, name resolution included); each accepted document becomes a public PKCE client limited to `twin:read` and is cached for one hour. One request at a time fetches each URL; a failed fetch starts no new one for 60 seconds, and while refreshes fail the last good client keeps serving for up to 24 hours after its cache expires. Listing a URL trusts its owner to define that client's redirect URIs. A malformed entry fails `./deploy.sh --check`, `admin.py` and web startup. |
| Corporate identity | `OIDC_ISSUER`, `OIDC_CLIENT_ID`, optional `OIDC_CLIENT_SECRET` | Authorized corporate IdP and exact identity callback `https://<host>/oauth/callback/identity`. Operator-provisioned roles/source identities remain a separate trusted input. |
| Slack activation | `SLACK_CLIENT_ID`, `SLACK_CONNECTOR_ENABLED`, `SLACK_POLICY_APPROVED` | Only after actual commercial permission, authorized PKCE app configuration and a permitted live grant/test. PKCE code exchange does not use a Slack client secret. Keep Slack token rotation off: no refresh tokens are stored. |
| Query source budget | `WISDOMTWIN_MAX_SOURCE_FETCHES` | Distinct sources one `query_twin` call may re-fetch; default `4`. Zero, negative or non-integer values stop startup. |
| Model operation | `OPENAI_API_KEY`, `OPENAI_EMBEDDING_MODEL`, `WISDOMTWIN_ALLOW_PAID_MODEL_APIS` | Separately authorized API spending is required for real indexed ingestion. Subscription credits do not establish API access. |
| Optional backend generation | `WISDOMTWIN_GENERATION_MODE`, `OPENAI_GENERATION_MODEL` | Default extractive evidence supports ChatGPT synthesis; backend Responses requires the same spending approval. |
| Responses budget | `OPENAI_MAX_OUTPUT_TOKENS` | Responses `max_output_tokens` (reasoning plus visible output); default `16000`. Must be a positive integer. The socket timeout is this budget divided by 50 seconds, between 60 and 600. |
| Responses effort | `OPENAI_REASONING_EFFORT` | Reasoning effort; default `low`. Allowed values: `low`, `medium`, `high`, `xhigh`, `max`. Any other value stops startup. |
| Hosted listing/challenge | `PRIVACY_POLICY_URL`, `TERMS_OF_SERVICE_URL`, `SUPPORT_URL`, `OPENAI_APPS_CHALLENGE` | Adopted published pages and portal's actual challenge; reconcile package metadata before release. |
| Guarded test modes | `WISDOMTWIN_USE_FIXTURES`, `WISDOMTWIN_AUTH_DISABLED`, `WISDOMTWIN_AUTH_DB` | Loopback synthetic tests only. Public deployment must keep fixture/auth-disabled modes off. |
| Gated Google scope | `GMAIL_CONNECTOR_ENABLED`, `DRIVE_CONNECTOR_ENABLED`, `GOOGLE_REVIEW_APPROVED`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | Remain off; provider verification and full-content implementation are unfinished. Google grants use online access, so they need reconnecting after the lifetime Google returns. |

No values, credentials, actual provider grants or adopted legal terms are supplied here. [.env.example](.env.example) supplies conservative defaults that match the code defaults: it lists `OAUTH_CIMD_CLIENT_IDS` (empty), `OPENAI_REASONING_EFFORT=low`, `OPENAI_MAX_OUTPUT_TOKENS=16000` and `WISDOMTWIN_MAX_SOURCE_FETCHES=4`. The code defaults also apply when a name is unset. `./deploy.sh` requires the OIDC names in addition to the core runtime names. Web startup requires `OAUTH_CLIENT_ID` and `OAUTH_REDIRECT_URIS` but not OIDC; without OIDC, corporate sign-in at `/oauth/consent` returns 503. A healthy container alone does not establish a working corporate/source login.

`./deploy.sh --deploy` copies only the names in its own lists to Railway, and only those that are non-empty in the calling shell. Those lists include `OAUTH_CIMD_CLIENT_IDS`, `WISDOMTWIN_MAX_SOURCE_FETCHES` and `OPENAI_MAX_OUTPUT_TOKENS`. A non-empty `OAUTH_CIMD_CLIENT_IDS` in that shell is forwarded and turns client metadata documents on with that deployment, so unset it before deploying unless that is intended. `./deploy.sh --check` validates the allowlist and performs no deployment.

The reverse proxy must preserve the Host header. A second public hostname, such as a custom domain next to the Railway domain, gets 421 on `/mcp` because only the `PUBLIC_BASE_URL` host is accepted.
